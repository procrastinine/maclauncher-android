# Bionic call frames

`call-packet.h` defines the versioned AAPCS64 input and output frame. The guest `klj_call_packet` entry accepts a trusted frame containing the target, x0–x8, q0–q7 and the exact converted stack bytes. It copies spilled arguments onto the original guest stack, calls the target and records the x0–x1 and q0–q3 results. x8 carries indirect aggregate result storage. An invalid size, version, target or stack shape returns negative EINVAL without changing the result storage. The stack limit follows the record capacity of the existing NativeABI descriptor.

`call-frame.c` reuses the complete existing `nativeabi.c` descriptor parser, immutable closure pages and cache, with separate Bionic closure names, and converts compact Darwin spills using those original records. `call-frame.S` captures the incoming JNI register frame before any C code runs and restores the integer and FP return registers afterward. The normal native ABI component still supplies environment-normalizer dispatch and the signed-page symbols.

The embedding JNI owner implements `klj_bionic_call_frame_invoke` for the typed Bionic image and the physical Java thread, decides which calls may enter, and handles pending Java exceptions and target lifetime. This component does not initialize a process, publish a library, bind JNI imports, run constructors or choose a runtime. Its source files are additive, and the normal load and ARM32 routes are unchanged.
